crappyemulator

Runs entirely in your browser. Nothing is uploaded anywhere.

Pick a game file. For PS1, select the .cue and .bin together.

What it emulates

  • NES / Famicom — .nes (iNES and NES 2.0 headers). Picture, sound, and the Zapper via mouse. Mappers 0, 1, 2, 3, 4, 5, 7, 9, 11, 34, 38, 66, 71, 79, 94, 118, 119, 140, 180, 240, 241.
  • SNES / Super Famicom — .sfc, .smc. 65816 CPU, PPU background modes 0–7, and SPC700 + DSP sound. LoROM and HiROM carts with SRAM; copier headers are stripped automatically. No enhancement chips — Super FX, SA-1, DSP-1, S-DD1, SPC7110 and CX4 games will not run. No DSP echo effect.
  • PlayStation (PS1) — .cue + .bin, or a single .iso / .img. No BIOS file needed. Much heavier than the other two; give it a few seconds to boot.

One player, keyboard only. No save states, no save files, no fast-forward, no gamepads. Refresh the page to load a different game. Bring your own game files.

Built on

  • NES: jsnes (Apache-2.0)
  • SNES: SnesJs (MIT)
  • PS1: wasmpsx (MIT)
